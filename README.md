# Zomato Restaurant Data Analysis Dashboard
## 📊 Project Overview
This project presents an interactive restaurant data analysis dashboard developed using Microsoft Power BI.
The dashboard analyzes restaurant information to identify patterns in restaurant ratings, cuisine preferences, geographic distribution, pricing, online delivery, and table booking adoption.

## 🎯 Project Objectives
- Analyze the total number of restaurants.
- Evaluate average restaurant ratings and total votes.
- Compare restaurant counts across countries and cities.
- Identify popular cuisines.
- Analyze restaurant distribution by price range.
- Examine online delivery adoption.
- Analyze table booking availability.
- Explore restaurant opening trends by year.

## 🛠️ Tools and Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning and Transformation
- Data Visualization
- Interactive Slicers and Filters

## 📌 Key Performance Indicators
The dashboard displays the following KPIs:
- Total Restaurants
- Average Rating
- Total Votes
- Online Delivery Percentage
- Average Cost for Two

The displayed dashboard reports approximately 9.55K restaurants, an average rating of 2.89, 1.50M votes, 25.66% online delivery, and an average cost for two of 1.20K.
These values reflect the displayed dashboard and may change when filters are applied.

## 🎛️ Interactive Filters
The dashboard includes slicers for:
- City
- Country
- Cuisine
- Price Range Category
- Online Delivery
- Table Booking
These filters help users explore different restaurant segments and compare performance across locations and categories.

## 💡 Business Insights
The dashboard can help identify:
- Cities with a higher concentration of restaurants.
- Differences in ratings across price categories.
- Popular cuisines and restaurant categories.
- The adoption of online delivery and table booking.
- Trends in restaurant openings over time.
- Relationships between ratings, votes, and cost.

## 🚀 Conclusion
This project demonstrates how Power BI can transform restaurant data into interactive visualizations and useful business insights. It showcases data preparation, dashboard design, KPI reporting, and interactive filtering for restaurant analysis.
